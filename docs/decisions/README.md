# Architecture Decision Records

One file per deviation from `docs/tdd.md`, numbered `NNNN-slug.md`. Overturning a decision is a new ADR that supersedes the old one.

Template:

```markdown
# NNNN — Title

**Status:** accepted | superseded by NNNN · **Date:** YYYY-MM-DD · **Session:** S0.x

## Context
What the TDD says, and why it doesn't work as written.

## Decision
What we do instead, precisely enough to implement.

## Consequences
What becomes easier, what becomes harder, what tests assert it.
```
