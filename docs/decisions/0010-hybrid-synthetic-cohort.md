# 0010 — The synthetic cohort is a hybrid: scripted brains beside model-driven ones

**Status:** accepted · **Date:** 2026-09-17 · **Session:** S1.16

## Context
ADR-0009 and the S1.16 card describe the synthetic cohort as eight LLM-driven players. Building it raised a cost that the card had not priced: at one turn per player per hour, an eight-player, seven-day epoch is about 1,300 model calls, roughly $12 to $28 a run depending on the model, and it cannot run in CI. Subscription pricing is not available to a harness like this: the Anthropic SDK and the Claude Agent SDK take API keys only, and the Agent SDK's documentation forbids claude.ai login for agents built on it. Local open-source models would be free per run but hours per epoch on one GPU, and a small model's confusions are too often its own reading failures to be good data.

Three of the eight personas are also better as code than as prose: the rule-prober is a fuzzer by another name, the wage-maximiser is a comparison every hour, and the speculator is a trailing mean. What only a model can do is read the game's words, try what nobody scripted, and say what it did not understand.

## Decision
1. **One harness, one seam.** `agents/` has a `Brain` interface. Every brain plays through the same tools (the public API, nothing else), is capped and journaled by the same `invoke`, and leaves the same journal line, so the report cannot tell them apart except by the `brain` field.
2. **Two brains.** The scripted brain is a strategy per persona slug, with a householder-like floor for any slug without one, and a fuzzer for the rule-prober that expects a refusal from every probe and journals an acceptance or a server error as `DEFECT:` and a refusal that names things by raw id as `COPY:`. The LLM brain is the Anthropic SDK's tool runner with the rules and the persona as a cached prefix, `end_turn` as the required last call, and a once-a-day reflection on a stronger model that rewrites the player's notes as structured output.
3. **Each persona names its default brain** in its frontmatter (scripted: rule-prober, wage-maximiser, speculator; llm: founder, borrower, landlord, saver, slacker), and a run may override all of them (`--brain scripted|llm|mixed`). The turn and cycle models are selectable per run (`--model`, `--cycle-model`, `config.toml`) and per persona (frontmatter), from a table that also carries prices, so an unknown model is refused before a token is spent.
4. **The scripted cohort is a CI regression.** `make e2e-agents` seeds a lab society, plays two one-second days with eight scripted players, and fails on any accepted probe or server error not listed in `agents/known-defects.txt`, on a 5xx in any journal, or on a turn that ended in error. It costs nothing and runs on every push. The model-driven cohort (`make agents`) is run by hand when the copy or a flow changes, against a per-run budget the harness enforces.
5. **Local models stay behind the seam.** The LLM brain's provider is one class; an OpenAI-compatible provider (for Ollama) can be added without touching the tools, the journal, or the report. It is not built in S1.16.

## Consequences
The done gate's "eight LLM players" becomes "eight players, of which the mixed run puts five on a model": the journals' `did_not_understand` data comes from those five, the strategic pressure and the refusal catalogue from all eight. The live run costs about half of what the card's all-LLM cohort would. A defect found by the fuzzer is filed in `docs/playtest/phase1-defects.md` and its probe name added to `agents/known-defects.txt` until it is fixed, so CI stays green on known problems and red on new ones. The replay test (`agents/test/replay.test.ts`) replays a scripted player's recorded epoch without the network; recording an LLM player is the same command with a key in the environment (`AGENTS_CMD=record`), and the transcript then also holds every model exchange.
