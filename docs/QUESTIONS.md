# Open questions and provisional answers

Where the GDD and TDD are silent or contradict each other, the executing agent records the question and a provisional answer here and proceeds on it. Each answer is in force until Chris overturns it; overturning one is an edit here plus, if code changed, an ADR. Structural deviations from the TDD are ADRs in `docs/decisions/` (referenced below), not entries here.

Numbering is stable; do not renumber. Add new entries at the end.
