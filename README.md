# Isms

A web-based multiplayer economic simulation: live in a society that runs one economic system, and feel how the system shapes your day.

- `docs/concept.md` — the pitch and open questions
- `docs/gdd.md` — the game design (rules, presets, axes)
- `docs/tdd.md` — the technical design and the session-by-session work breakdown
- `docs/wireframes.pdf` — Freeport / Commune / Directorate screens
- `docs/SESSIONS.md` — what has been built, card by card
- `docs/QUESTIONS.md` — spec gaps and the provisional answers in force
- `docs/decisions/` — ADRs where the build deviates from the TDD

`make check` is the gate for every change. See `CLAUDE.md` for agent conventions.
